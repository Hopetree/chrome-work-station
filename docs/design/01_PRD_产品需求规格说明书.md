# 01 PRD — 产品需求规格说明书

## 1. 产品定位

**Chrome 工作站**：面向开发者的浏览器多功能效率工具合集。每个能力（功能模块）有独立界面与独立数据，在一个插件内按需扩展。

- 目标用户：插件作者本人（日常需要编写、复用 Prompt 的开发者）；设计上不排除其他开发者使用
- 形态：Chrome MV3 扩展（WXT），数据全部本地存储，无账号、无服务端

## 2. 产品原则

1. **模块化**：功能彼此隔离，可独立开发、独立隐藏（`FeatureModule.hidden`），一个功能的问题不影响其他功能
2. **本地优先**：数据只在浏览器本地，提供导出/导入保证资产可迁移
3. **完整度高于可用**：每个功能按「沉淀 → 整理 → 复用 → 迭代」闭环设计，而非最小可用堆叠
4. **视觉统一**：青绿（teal）/冷灰（zinc）设计语言，禁止原生控件默认外观

## 3. 功能需求

### 3.1 工作台（容器）

- 侧边栏功能菜单（工具架式，活动项有青绿刻度标识），深色底
- 深链：`workbench.html?feature=<id>` 直达功能，URL 同步
- popup 为启动菜单：功能卡片直达 + 「打开工作台」（进设置页配置的默认功能）+ 设置入口

### 3.2 Prompt 管理

用户故事与对应能力：

| 用户故事 | 能力 |
|----------|------|
| 我经常写长 Prompt，会换行，希望能编辑并保存，回来继续改 | 多行编辑器（行号、等宽字体）、600ms 防抖自动保存、保存状态提示、重进自动选中最近编辑 |
| 有些 Prompt 是固定骨架，只有几个词每次不同 | `{{变量}}` 占位符：复制时弹填空面板生成即用内容；支持复制原文；变量值跨打开保留 |
| 常用的希望一眼能找到 | 置顶（卡片悬停星标 / 编辑区切换），置顶优先排序；搜索（标题+正文） |
| 想知道哪些 Prompt 真的在用 | 复制次数统计，卡片与编辑区展示 |
| 高频操作不想多点几步 | 卡片悬停操作组：置顶 / 直接复制 / 删除 |
| 固定骨架想沉淀成模板反复用 | 「存为模板」；模板独立列表（带图标区分）；点击浏览/编辑模板（自动保存）；卡片 + 或预览页「基于模板新建」；删除模板有确认且不影响已建 Prompt |

### 3.3 数据备份（设置页）

- 导出：全部 Prompt + 模板为 JSON 文件
- 导入：按条目合并（id 对齐、updatedAt 新者胜），反馈新增/更新条数
- 设置：popup「打开工作台」默认进入的功能

### 3.4 明确不做（当前阶段）

- 云同步、账号体系、多人协作
- 标签/分组（搜索+置顶未出现瓶颈前不加）
- 编辑历史版本
- Firefox / Edge 适配（构建命令预留，未验证）

## 4. 验收标准

- 所有写操作自动保存，无「保存按钮」心智；保存失败有状态提示不静默丢数据
- 旧版本数据无新字段时可正常加载（字段级回退，无迁移脚本）
- 复制含变量 Prompt 必须经过填空面板，未填变量保留原文
- 删除类操作必须经过定制确认弹窗
- 全部交互可用键盘完成（下拉、弹窗的 Esc/Enter/方向键）
